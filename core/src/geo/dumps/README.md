# Test data

An excerpt of the GeoNames dumps, kept here so the place lookup can be tested offline and
always gives the same answers. Cut from `cities1000`, `admin1CodesASCII`, `countryInfo` and
`shapes_simplified_low` on 2026-09-23: the cities the tests name, everything around the corner
where Germany, France and Switzerland meet, and the outlines of seven countries.

This data is from [GeoNames](https://www.geonames.org/) and is licensed under
